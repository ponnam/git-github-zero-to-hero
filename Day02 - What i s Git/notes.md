# 📌 What is Git?

**Git** is a **Distributed Version Control System (DVCS)** created by **Linus Torvalds** in 2005.

It was originally developed to manage the development of the Linux kernel, and today it is the most widely used version control system in the world.

Git allows multiple developers to:
- Work on the same project simultaneously
- Track changes efficiently
- Collaborate without conflicts

---

# 🚀 Why Git is Popular?

- Fast and efficient
- Works offline
- Powerful branching & merging
- Strong data integrity
- Flexible collaboration

---

# 🔑 Key Features of Git

## 1. Distributed Architecture
- Every developer has a **full copy of the repository**
- No dependency on a central server

## 2. Branching and Merging
- Create branches easily
- Work on features independently
- Merge changes efficiently

## 3. Speed
- Most operations happen locally
- Faster than centralized systems

## 4. Data Integrity
- Uses **SHA-1 hashing**
- Each commit has a unique ID
- Prevents data corruption

## 5. Distributed Collaboration
- Developers can collaborate using:
  - Push
  - Pull
  - Branch sharing

# 🔁 Git Workflow (Stages)

Git works in **multiple stages**:

---

## 1. Working Directory
- Where you modify files

## 2. Staging Area (Index)
- Where you prepare changes

## 3. Local Repository
- Where commits are stored

## 4. Remote Repository
- Shared version (GitHub)

---

## 🔄 Flow Diagram (Conceptual)

Working Directory → Staging Area → Local Repository → Remote Repository  
    (edit)    (add)    (commit)    (push)


---


# 🖥️ Working Directory

- Your **actual project folder**
- Where you create/edit files
- Represents the current version of your project

---

# 📦 Staging Area (Index)

- Intermediate area before commit
- Used to prepare changes

---

# 💾 Local Repository

- The **local repository** is stored on your system inside the `.git` folder
- It contains:
  - All commits
  - Full project history
- When you run `git commit`, changes are saved here

### Key Points:
- Works completely offline
- Fast operations (no internet required)
- Acts as your personal version control database

---

# 🌐 Remote Repository

- A **remote repository** is hosted on a server

### Examples:
- GitHub
- GitLab
- Bitbucket

- Used for:
  - Backup
  - Collaboration
  - Sharing code with team members


### Key Points:
- Enables team collaboration
- Acts as a central/shared repository
- Requires internet connection

---


# 🧠 Key Takeaways

- Git is a **Distributed Version Control System**
- It allows **fast, flexible, and safe collaboration**
- Works both **offline and online**
- Uses staging → commit → push workflow
- Industry standard for modern development
