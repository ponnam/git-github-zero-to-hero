# 🧪 Day 04 - Hands-on Lab (GitHub Account Creation)

In this hands-on session, we will:
- Create a GitHub account
- Understand basic profile setup
- Explore the GitHub dashboard

---

## 🌐 Task 1: Create a GitHub Account

### Step 1: Open GitHub Website
Go to:
https://github.com

---

### Step 2: Click on Sign Up
- Click on the **Sign up** button (top right corner)

---

### Step 3: Enter Your Details

Provide the following information:
- Email address
- Password
- Username

👉 Choose a professional username (recommended for career use)

---

### Step 4: Verify Your Account
- Complete the verification (puzzle or code)
- Click **Create account**

---

### Step 5: Email Verification
- Check your email inbox
- Enter the verification code sent by GitHub

---

## ⚙️ Task 2: Complete Profile Setup

After login:

### Add Profile Details:
- Profile Picture
- Full Name
- Bio (optional but recommended)

---

### Example Bio:

```bash
DevOps Learner | Git & GitHub | Cloud Enthusiast
```


---

## 🖥️ Task 3: Explore GitHub Dashboard

After logging in, you will see:

### Key Sections:
- **Repositories** → Your projects
- **Profile** → Your personal details
- **Explore** → Discover projects
- **Notifications** → Updates
