# 🧪 Day 05 - Hands-on Lab - Visual Studio Code Setup


In this hands-on session, we will:
- Install Visual Studio Code
- Configure essential extensions (plugins)
- Perform basic setup for development

---

## 💻 Task 1: Install Visual Studio Code

### Step 1: Download VS Code

Go to the official website:  
https://code.visualstudio.com/

---

### Step 2: Install VS Code

#### For Windows:
1. Download the installer
2. Run the setup
3. Select the following options:
   - ✅ Add to PATH
   - ✅ Add "Open with Code" option
4. Click **Install**

---


### Step 3: Verify Installation

Open VS Code from:
- Start Menu (Windows)
- Applications (Linux)

---

## 🔌 Task 2: Install Essential Extensions (Plugins)

### Step 1: Open Extensions Panel
- Click on **Extensions icon** (left sidebar)  
  OR  
- Press: `Ctrl + Shift + X`

---

### Step 2: Install Recommended Extensions

Search and install the following:

- GitLens → Enhanced Git capabilities  
- Prettier → Code formatter  
- Python → Python support  
- Java Extension Pack → Java development  
- Docker → Container support  

---

## ⚙️ Task 3: Basic Setup

### 1. Set Theme
- Go to: `File → Preferences → Color Theme`
- Choose a theme (e.g., Dark+)

---

### 2. Enable Auto Save
- Go to: `File → Auto Save`

---

### 3. Set Default Terminal
- Open Terminal:
  `Ctrl + ~`
- Choose:
  - PowerShell / Command Prompt (Windows)
  - Bash (Linux)

---

### 4. Open a Folder

- Click: **File → Open Folder**
- Select your project folder

---

### 5. Create a New File

- Right-click → New File  
- Example: `test.txt` or `app.py`
