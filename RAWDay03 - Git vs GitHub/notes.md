# 📌 What is Git?

- **Git** is a **Version Control System (VCS)**
- Used to track changes in code
- Works locally on your machine
- Helps manage project history

### Key Points:
- Distributed system (DVCS)
- Works offline
- Tracks changes (commits)
- Supports branching & merging

---

# 🌐 What is GitHub?

- **GitHub** is a **Git hosting platform**
- It stores your Git repositories on the cloud
- Enables collaboration between developers

### Key Points:
- Cloud-based platform
- Provides UI for Git
- Enables team collaboration
- Supports pull requests, issues, actions

---

# ⚖️ Git vs GitHub

| Feature | Git | GitHub |
|--------|-----|--------|
| Type | Version Control Tool | Hosting Platform |
| Works On | Local Machine | Cloud |
| Purpose | Track code changes | Store & share code |
| Internet | Not required | Required |
| Collaboration | Limited | Strong |

---

# 🔍 Simple Understanding

- **Git = Tool**
- **GitHub = Platform**

👉 You use **Git** to manage code  
👉 You use **GitHub** to share and collaborate  

---

# 🌍 Other Git Hosting Platforms

Apart from GitHub, there are other platforms:

- GitLab
- Bitbucket
- Azure Repos

### Key Differences:
- Some provide built-in CI/CD (like GitLab)
- Some are enterprise-focused (like Bitbucket)

---

# 🧩 GitHub Ecosystem

GitHub provides many features beyond just storing code.

---

## 📂 1. Repositories

- A **repository (repo)** is a project
- Contains:
  - Code
  - History
  - Branches

👉 Can be:
- Public
- Private

---

## 🔁 2. Pull Requests (PR)

- Used to **merge changes** into main branch
- Enables:
  - Code review
  - Discussion
  - Collaboration

👉 Common workflow:
1. Create branch  
2. Make changes  
3. Create PR  
4. Review & merge  

---

## 🐞 3. Issues

- Used to track:
  - Bugs
  - Tasks
  - Feature requests

👉 Helps in:
- Project management
- Team communication

---

## ⚙️ 4. GitHub Actions

- Used for **automation (CI/CD)**

👉 Example:
- Build code
- Run tests
- Deploy applications

---

# 🧠 Key Takeaways

- Git is a **version control tool**
- GitHub is a **hosting platform**
- Git works locally, GitHub works on cloud
- GitHub provides powerful collaboration features
- PRs, Issues, and Actions are core parts of GitHub ecosystem
